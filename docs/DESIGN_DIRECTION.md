# HalalLens Design Direction

The visual direction is inspired by the provided HalalLens concept image.

## Interface Style
- Dark futuristic AI analysis environment
- Cyan/teal glowing accents
- Glassmorphism panels
- Soft HUD-inspired details
- Minimal but premium technology feeling

## Main Experience
The application should feel like a smart scanner:

1. Capture product label
2. Read ingredients
3. Analyze ingredient sources
4. Explain transparent results

## Important UI Rules
- Never show religious permission as a probability score.
- Confidence represents analysis reliability only.
- Unknown ingredient sources must remain NEEDS VERIFICATION.

## Result Visual Language
- Green: HALAL
- Red: NOT HALAL
- Amber: NEEDS VERIFICATION

The image is used as inspiration for atmosphere, layout, and interaction design, while keeping the application practical and accessible on mobile.
